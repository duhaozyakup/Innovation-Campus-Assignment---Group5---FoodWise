# FoodWise

**AI-Powered Recipe Recommendations for Sustainable Food Consumption**  
*Assignment 1: Project Selection & Exploratory Data Analysis (EDA)*  
*Group 5: Sunar, Tan, Açıkel, Özyakup*

FoodWise is a recipe recommendation project aligned with **UN Sustainable Development Goal 12 (Target 12.3: Food Waste Reduction)**. It helps households and community kitchens find recipes based on ingredients they already have, prioritizing stock nearing its use-by date to prevent food waste.

---

## Project Overview

- **Report (PDF):** `report/Sunar_Tan_Acikel_Ozyakup_Group5.pdf` (or `report/FoodWise_Concept_Note_Group5.pdf`)
- **EDA Notebook:** `notebooks/FoodWise_Assignment1.ipynb`
- **Dataset:** Curated sample of 8,000 real recipes from Food.com (`data/recipes_sample.jsonl`)
- **Example Inventory:** Sample pantry ingredients with use-by dates (`data/example_inventory.json`)

---

## Quick Start

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **View the Report:**
   Open the submitted PDF concept note in the `report/` folder.

3. **Run the EDA Notebook:**
   Open `notebooks/FoodWise_Assignment1.ipynb` in Jupyter, VS Code, or Google Colab and run the cells.  
   Alternatively, you can run the notebook directly from the terminal:
   ```bash
   python scripts/build_notebook.py
   ```

---

## Repository Structure

- `report/` — Project Concept Note and Proposal PDF.
- `notebooks/` — Main exploratory data analysis notebook (`FoodWise_SDG12_EDA.ipynb`).
- `data/` — 8,000-recipe curated sample and example inventory.
- `outputs/` — Figures, distribution plots, and summary CSVs generated by the EDA.
- `scripts/` — Helper scripts for data preparation (`prepare_data.py`) and notebook execution (`build_notebook.py`).
- `src/` — Python helper modules for data loading and plotting.
